# tools/archive

سكربتات إصلاح وفحص استُخدمت مرة واحدة أثناء التطوير (تصدير PDF/Excel، تنظيف بيانات تجريبية، ترقيع شاشات الموبايل).
**لا تُشغَّل ضمن العمل العادي ولا يعتمد عليها البناء أو CI.** نُقلت هنا للاحتفاظ بالتاريخ فقط.

الأداة الوحيدة الحية في `tools/` هي `db-import/` (فحص وتحويل قاعدة البيانات القديمة).

Single-use fix and diagnostic scripts kept for history. Nothing in the build or CI depends on them.
Note: some historical notes (e.g. `Mobile/AssetXMobile/todo.md`) still mention the old `tools/<name>.js` paths.
