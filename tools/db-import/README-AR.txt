فحص بيانات SQL Server — AssetX
=================================

ما الذي يفعله هذا الملف؟
-------------------------
يقرأ فقط «أسماء الجداول والأعمدة» من قاعدة بياناتك القديمة
ليعرف برنامج التحويل شكل بياناتك، تمهيداً لنقلها إلى النظام الجديد.

⚠️ هذا الملف للقراءة فقط — لا يعدّل ولا يحذف أي بيانات إطلاقاً.

طريقة التشغيل (خطوة واحدة)
----------------------------
انقر نقرتين على الملف:  1-inspect-db.bat

سيفتح الملف تلقائياً:
  1) أداة sqlcmd الخاصة بـ SQL Server (تأتي معه).
  2) يبحث عن السيرفر المحلي ويتصل به.
  3) يكتب تقريراً ثم يفتحه أمامك في Notepad.

المطلوب منك
------------
انسخ كل محتوى نافذة Notepad وأرسله لي في المحادثة.
(أو أرسل صورة واضحة للنافذة، أو أرسل الملف نفسه)

إذا ظهرت رسالة خطأ بهذه الصيغة [ERROR] ... أرسلها لي كما هي تماماً.

الطريقة البديلة (إن لم تعمل الأداة)
-------------------------------------
افتح برنامج SQL Server Management Studio ثم:
  1) اضغط New Query
  2) افتح الملف inspect.sql وانسخ محتواه والصقه في النافذة
  3) اضغط Execute  (أو F5)
  4) انسخ النتائج كلها وأرسلها لي

ماذا سيظهر في التقرير؟
-----------------------
1) قواعد البيانات الموجودة على السيرفر
2) كل الجداول مع عدد الصفوف في كل جدول
3) أسماء الأعمدة وأنواعها
4) العلاقات بين الجداول (أي جدول يرتبط بأي جدول)
5) عيّنة من بيانات الجداول الرئيسية (3 صفوف لكل جدول)

ملاحظة: هذا الملف آمن ويمكن حذفه بعد انتهاء العملية.

إذا طلب منك البرنامج شيئاً (مهم)
----------------------------------
1) «Server name:» أي اسم السيرفر:
   افتح SQL Server Management Studio وانظر السطر العلوي،
   واكتب الاسم كما هو. مثال: ABDULHAMEED-ALS\SQLEXPRESS02
2) «SQL username:» أي اسم مستخدم قاعدة البيانات:
   اضغط Enter فقط بدون كتابة شيء إذا كنت تعمل بنفس أسلوب
   الدخول المعتاد في Management Studio.

ملاحظة: إن كتبت اسماً غير صحيح وظهرت رسالة [ERROR]، أغلق النافذة
وأعد تشغيل الملف من جديد وجرّب اسماً آخر.
