تحويل بيانات AssetX القديمة إلى ملفات Excel
==============================================

ماذا يفعل هذا الملف؟
---------------------
يقرأ بياناتك القديمة من قاعدة بيانات SQL Server (AssetsDB)
ويحوّلها إلى خمسة ملفات Excel جاهزة للاستيراد في النظام الجديد:
  1-locations.xlsx   المواقع (الرئيسية والفرعية بترتيبها الصحيح)
  2-categories.xlsx  أنواع الأصول (الأنواع والأنواع الفرعية)
  3-statuses.xlsx    حالات الأصول مع ألوانها
  4-employees.xlsx   الموظفون
  5-assets.xlsx      الأصول (1982 أصلاً) مع نوعها وموقعها وحالتها

⚠️ قاعدة البيانات القديمة للقراءة فقط: لا يعدّل ولا يحذف أي شيء.

طريقة التشغيل (خطوة واحدة)
----------------------------
انقر نقرتين على الملف:  2-convert-db.bat

سيتصل بالأداة تلقائياً بالسيرفر .\SQLEXPRESS02 وقاعدة AssetsDB،
ثم يكتب الملفات في مجلد out ويفتح لك:
  - تقرير التحويل (conversion-report.txt)
  - مجلد الملفات الجاهزة (out)

إن لم يتصل تلقائياً، شغّل الملف من نافذة الأوامر بهذا الشكل:
  2-convert-db.bat --server "ABDULHAMEED-ALS\SQLEXPRESS02" --database AssetsDB

ماذا بعد ذلك؟
--------------
1) ادخل النظام الجديد ثم صفحة "استيراد البيانات".
2) اختر "المواقع" وارفع 1-locations.xlsx ثم اضغط تنفيذ الاستيراد.
3) ثم بالترتيب: الأنواع (2) ثم الحالات (3) ثم الموظفون (4) ثم الأصول (5).
   الترتيب مهم: الأصول تحتاج المواقع والأنواع والحالات والموظفين.

ملاحظات
--------
- إن ظهرت رسالة أن بعض السجلات "موجودة مسبقاً" فهذا طبيعي: يتم تخطيها.
- الموديلات والمستخدمون ودورات الجرد لا تُنقل في هذه المرحلة
  (غير مدعومة في صفحة الاستيراد) وسننقلها بطريقة مستقلة لاحقاً.
- كل الأسماء المكررة في بياناتك القديمة تم توضيحها في تقرير التحويل.

إذا ظهر خطأ
-----------
انسخ لي الكود الظاهر فقط:
NO-NODE أو NO-SQLCMD أو NO-CONNECTION أو NO-DATABASE
