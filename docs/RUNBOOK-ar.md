# دليل التشغيل السريع — AssetX (محلي)

هذا الدليل للمالك (غير مبرمج): كيف تحمي بياناتك، وكيف تتأكد أنها قابلة للاستعادة، وماذا تفعل عند حدوث مشكلة.

## 1) النسخ الاحتياطي التلقائي

**ما هو؟** نسخة كاملة من قاعدة البيانات `assetx` تُحفظ كل يوم تلقائياً في مجلد على جهازك. إذا تعطّل الجهاز أو حُذفت بيانات بالخطأ، ترجع منها.

**التفعيل (مرة واحدة فقط)** — افتح PowerShell داخل مجلد المشروع ونفّذ:

```powershell
powershell -File scripts\db-backup-setup.ps1
```

- يطلب كلمة مرور المستخدم `assetx_migrator` (نفس كلمة المرور التي كنت تدخلها في سكربت التحديث). لا تظهر على الشاشة.
- يتحقق منها، ثم يحفظها في ملف PostgreSQL القياسي `%APPDATA%\postgresql\pgpass.conf` داخل حسابك على ويندوز فقط، ليعمل النسخ التلقائي دون سؤالك كل مرة.
- يأخذ أول نسخة فوراً، ثم يُنشئ مهمة ويندوز اسمها `AssetX-DB-Backup` (يومياً 1:30 ظهراً وعند تسجيل الدخول؛ وإذا كان الجهاز مطفأً تعمل عند تشغيله).

**أين النسخ؟** `Documents\assetx-backups\daily\` (ملف لكل يوم `assetx-YYYYMMDD.dump`، ويُحتفظ بآخر 14 يوماً). السجل في `Documents\assetx-backups\backup.log`: كل سطر يبدأ بـ `OK` (نجحت) أو `FAIL` (فشلت).

**نسخة يدوية الآن:**

```powershell
powershell -File scripts\db-backup.ps1 -Force
```

> مهم: النسخ على نفس الجهاز لا تحميك من تلف القرص أو سرقة الجهاز. انسخ المجلد `assetx-backups` دورياً إلى فلاش أو قرص خارجي أو سحابة خاصة بك (مرة أسبوعياً مثلاً).

## 2) التأكد أن النسخة تُستعاد فعلاً

نسخة لم تُجرَّب ليست مضمونة. هذا السكربت يستعيد أحدث نسخة في قاعدة **مؤقتة** ويقارن عدد السجلات مع قاعدتك الحية ثم يحذف المؤقتة. **لا يلمس قاعدتك الحقيقية.**

```powershell
powershell -File scripts\db-restore-check.ps1
```

- يطلب كلمة مرور المستخدم `postgres` (المدير) ولا يحفظها.
- النتيجة المطلوبة: `RESULT: the backup restored correctly.`
- كرّره مرة كل شهر تقريباً.

## 3) الاستعادة الحقيقية (عند الكارثة فقط)

1. أوقف الخادم (Backend) وأغلق برنامج الويب.
2. أخبرني، وسأعطيك الأمر الدقيق لاستبدال قاعدة العمل بالنسخة التي تختارها. لا تنفّذ استعادة فوق قاعدة العمل بنفسك قبل أن تأخذ نسخة من حالتها الحالية.

## 4) أعطال شائعة

| العَرَض | السبب والحل |
|---|---|
| سطر `FAIL` في السجل | PostgreSQL متوقف (شغّل الخدمة)، أو تغيّرت كلمة مرور `assetx_migrator` (أعد تشغيل `db-backup-setup.ps1`) |
| الهاتف لا يتصل بالخادم | تغيّر عنوان IP للكمبيوتر. تحقق منه بالأمر `ipconfig` وحدّث عنوان الخادم في الهاتف. الأفضل تثبيت العنوان من إعدادات الراتر (حجز DHCP) |
| بعد تحديث المشروع تظهر أخطاء قاعدة بيانات | شغّل سكربت تحديث القاعدة الموجود على جهازك `scripts\db-update-local.ps1` (غير مرفوع إلى GitHub عمداً؛ يأخذ نسخة أمان ثم يطبّق المهاجرات الناقصة) |

## 5) إيقاف النسخ التلقائي

```powershell
Unregister-ScheduledTask -TaskName AssetX-DB-Backup -Confirm:$false
```
