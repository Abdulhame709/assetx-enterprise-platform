# Legacy Reference Archive

هذا المجلد يحفظ **مرجعاً تاريخياً انتقائياً** للنظام السابق الذي كان مبنياً على WPF وC# وSQL Server. الملفات هنا لا تدخل في build منصة AssetX الحالية، ولا تمثل عقد API أو مخطط قاعدة البيانات المعتمد للمنصة الجديدة. الغرض منها هو الرجوع إلى الإجراءات وتجربة الاستخدام والسلوكيات المفيدة عند تنفيذ تحسينات Web أو تطبيق الهاتف.

## المحتوى المحفوظ

| المسار | المحتوى | طريقة الاستخدام |
|---|---|---|
| `source/` | ملفات C# المصدرية للخدمات والمساعدات والنماذج والتقارير والصلاحيات | مرجع للسلوك والإجراءات فقط، ولا تُستورد إلى TypeScript |
| `ui/` | ملفات XAML الأصلية للشاشات | مرجع للتخطيط، الحقول، الأزرار، التبويبات والمسافات فقط |
| `conversation/` | نصوص التصميم والمحادثات والقرارات المرفقة | مرجع للسياق والقرارات السابقة، مع اعتماد وثائق AssetX الحالية عند التعارض |
| `metadata/` | ملفات موارد وإعدادات غير تنفيذية | مرجع محدود؛ لا تُستخدم كمصدر أسرار أو إعداد تشغيل |

## ما تم استبعاده عمداً

تم استبعاد ملفات `.exe` و`.pdb` و`vshost` و`.baml` وملفات `*.g.cs` و`*.g.i.cs` وملفات build المولدة. هذه الملفات إما ثنائية أو ناتجة عن أدوات البناء أو مرتبطة ببيئة سطح المكتب، ولا تضيف قيمة آمنة إلى مستودع AssetX الحالي.

تم استبعاد ملف الإعداد القديم `AssetManagement.exe.config` بصيغته الأصلية لأنه يحتوي على اسم جهاز SQL Server داخلي. كما لم تُحفظ أي كلمة مرور أو `DATABASE_URL` أو JWT secret أو مفتاح API. لا يُسمح بإضافة ملفات أسرار إلى هذا المجلد مستقبلاً.

## قواعد الاقتباس في التطوير

عند تنفيذ ميزة جديدة، يجب أولاً مقارنة الفكرة مع صفحات وواجهات AssetX الحالية. تُقتبس الوظائف التي تضيف قيمة مثل البحث الذكي، تفاصيل حركة الأصل، تقارير الفلاتر، ملخصات الجرد، وسجل الأخطاء في الاستيراد. لا تُنقل النوافذ أو أحداث WPF أو `MessageBox` أو اتصال SQL Server المباشر؛ يعاد تنفيذ السلوك في Next.js/React وBackend وPostgreSQL وواجهات API متعددة المستأجرين.

إذا تعارض هذا المرجع مع `docs/PROJECT_UNDERSTANDING_REPORT.md` أو مخطط PostgreSQL أو عقود API، تكون وثائق AssetX الحالية والكود الجاري المصدر المعتمد، ويظل هذا المجلد مرجعاً تاريخياً فقط.

## حساب المعاينة

يوجد حساب معاينة محلي باسم `demo_admin` على tenant `local_assetx` لغرض مراجعة رابط Web المؤقت. لا تُحفظ كلمة مرور الحساب في GitHub أو هذا الملف. عند فقدانها يجب إنشاء كلمة مرور مؤقتة جديدة من مسار الإدارة أو تعطيل الحساب وإعادة إنشائه، ثم تدويرها قبل أي استخدام فعلي.

## حدود أمنية

لا تُشغّل أي ملف من هذا المجلد تلقائياً. لا تُنفّذ استعلامات SQL أو scripts قديمة لمجرد وجودها في المرجع. يجب تحليل كل فكرة وإعادة تنفيذها ضمن نموذج الصلاحيات وRLS والمستأجر في AssetX. لا تُرفع ملفات ثنائية أو أسرار أو dumps أو نسخ قواعد البيانات إلى هذا المسار.
