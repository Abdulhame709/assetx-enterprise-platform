# تقييم ميزات التقارير والطباعة في النظام السابق

**النطاق:** ملفات `docs/legacy-reference/source` داخل مستودع AssetX فقط.

## المصادر التي تمت مراجعتها

| الملف | الميزات المستخرجة |
|---|---|
| `AssetsReportForm.xaml.cs` | فلاتر متعددة للأصول، موقع هرمي يشمل المواقع الفرعية، النوع الفرعي، الحالة، الموظف، الموديل، نطاق السعر، نطاق تاريخ الشراء، سنة الجرد، الباركود/الرقم التسلسلي، بحث داخل النتائج، تقرير تفصيلي قابل لتحديد الأعمدة، تقرير مجمع حسب أكثر من محور، بطاقات إحصائية، وصف للفلاتر، معاينة، طباعة، CSV وExcel. |
| `InventoryReportForm.xaml.cs` | اختيار دورة الجرد، فلتر الموقع، فلتر نتيجة الجرد، بطاقات مطابق/عجز/زيادة/منقول/مفقود/لم يجرد، نسبة الإنجاز، النقر على بطاقة النتيجة لتطبيق الفلتر، CSV للطباعة والتصدير، وطباعة مباشرة للجدول. |
| `ReportEngine.cs` | تقرير صفحات متعددة، رأس ثابت، عنوان فرعي، شريط وصف الفلاتر، جدول RTL، ترقيم الصفحات، تذييل يحوي المستخدم والتاريخ، حساب عرض الأعمدة ديناميكياً، صف إجمالي، تلوين الصفوف المجمعة، ومساحات توقيعات للمستلم وأعضاء اللجنة ورئيسها. |
| `ReportPreviewWindow.xaml.cs` | معاينة قبل الطباعة، عدد الصفحات والسجلات، طباعة، تصدير Excel، وأزرار تكبير وتصغير. |
| `ExcelExporter.cs` | ملف Excel غني بالعنوان والجهة وتاريخ التصدير والمستخدم ووصف الفلاتر، دعم RTL، تجميد الرؤوس، ملاءمة الطباعة، عرض أعمدة حسب نوع البيانات، صفوف متناوبة، تنسيق رقمي ومالي، صف إجمالي، تذييل، وAutoFilter. |
| `ReportHelper.cs` | HTML قابل للطباعة والتصدير إلى Excel، CSV، عناوين وسياق التقرير، تلوين دلالي للنتائج، تقرير جرد فارغ مجمع حسب الموقع، وتوقيعات. |

## الأولويات المقترحة للنقل إلى AssetX

| الأولوية | الميزة | سبب الملاءمة |
|---:|---|---|
| P0 | إخراج طباعة مخصص بوسم `print` | الطباعة الحالية تعتمد على `window.print()` دون إخفاء عناصر التحكم أو إضافة رأس وتذييل واضحين. |
| P0 | ملخص الفلاتر في التقرير المطبوع والتصدير | يزيد قابلية التدقيق ويبين للمستخدم كيف تم تضييق النتائج. |
| P1 | تقرير تفصيلي بصفحة متعددة وترويسة وتذييل | يتوافق مع تقارير الأصول والحركات والجرد الحالية ويصلح للطباعة وPDF. |
| P1 | صف إجمالي وتنسيق رقمي/مالي | مفيد للأصول والجرد، مع ضرورة اعتماد مجموع الكمية والقيمة فقط حيث تكون الحقول موجودة. |
| P1 | تقرير الجرد ببطاقات نتائج ونسبة إنجاز | يعكس التدفق الميداني الحالي ويبرز المطابق والفروقات والمنقول والمفقود. |
| P2 | تحديد الأعمدة وقوالب التقارير المحفوظة | مفيد، لكنه يحتاج عقداً واضحاً لتجنب إنشاء تقارير لا يدعمها backend. |
| P2 | معاينة قبل الطباعة والتكبير | فكرة جيدة للويب، ويمكن تنفيذها كـ preview HTML أو print preview دون نقل WPF/XPS. |
| P3 | خانات التوقيع وأعضاء اللجنة | مناسبة لتقرير جرد رسمي، لكنها تحتاج متطلبات اعتماد قبل جعلها جزءاً تشغيلياً دائماً. |

## قرار النقل

لن يتم نسخ WPF أو XPS أو SQL القديم إلى المنصة. سيتم نقل الأفكار القابلة للتنفيذ في Next.js وbackend الحالي فقط، مع الإبقاء على endpoints الحقيقية وعزل الجهة والصلاحيات. ستظل قاعدة البيانات المحلية خارج التنفيذ.
