| الملف | الغرض |
|---|---|
| `assetx-demo-report-preview.html` | معاينة مرئية RTL قابلة للفتح في المتصفح أو الطباعة، وتحتوي على بطاقات المؤشرات، أشرطة التوزيع، وسجلات الأصول والحركات ونتائج الجرد. |
