# تحقق بصري — الإعدادات والثيمات وأنواع المواقع

تم فتح صفحة `/settings` في نسخة standalone النهائية بعد تشغيل backend على 3001 وNext على 3010. صفحة login وdashboard وsettings حملت دون spinner أو أخطاء route، وظهرت جلسة admin العربية.

ظهرت أربعة ثيمات قابلة للاختيار: أزرق مؤسسي، منتصف الليل، زمردي، وجرافيت. المظهر العام للبطاقات والمعاينات متسق، والثيم الافتراضي مميز بعلامة اختيار.

ظهرت قائمة أنواع المواقع القياسية الخمسة من catalog: مبنى، غرفة، مستودع، ورشة، وموقع خارجي. لكل صف حالة نشط، شارة نوع نظامي، الرمز الداخلي، الترتيب، وأزرار تعديل وتعطيل icon-only مع hints.

الملاحظة البصرية غير الحاجبة: صفحة الإعدادات على viewport ضيق تعرض القائمة الجانبية إلى اليمين والمحتوى داخل مساحة ضيقة مع تمرير رأسي، وهو سلوك responsive قائم يحتاج تحسيناً مستقلاً لاحقاً إن أردنا mobile-first أقوى. لم يُعتبر ذلك فشلاً وظيفياً في هذه المرحلة لأن جميع الإجراءات الأساسية ظهرت وكانت قابلة للوصول.

## تحقق ثيم منتصف الليل

تم اختيار ثيم منتصف الليل من بطاقة الثيمات. تحولت الخلفية والأسطح والـsidebar إلى كحلي داكن، وبقيت النصوص والأزرار والعناصر النشطة مقروءة في viewport RTL. ظهرت علامة الاختيار على الثيم المحدد، وبقيت قائمة أنواع المواقع وأزرارها قابلة للوصول. لا توجد مشكلة runtime ظاهرة في هذا المسار.

## تحقق نموذج نوع موقع

فُتح نموذج «نوع موقع جديد» بصرياً، وظهرت حقول الرمز والاسم العربي والاسم الإنجليزي والأيقونة والترتيب، مع تسع خيارات أيقونات مدعومة. ظهر زر الإلغاء والحفظ، وأُغلق النموذج دون حفظ بيانات. لم تظهر مشكلة runtime في Modal، وكانت الخلفية والـfocus overlay متسقين مع الثيم الداكن.

## تحقق صفحة المواقع

فُتحت صفحة `/locations` في ثيم منتصف الليل، ثم فُتح نموذج «إنشاء موقع رئيسي». ظهرت خيارات النوع الخمسة القادمة من endpoint `/location-types` داخل select، وظهرت إشارة مباشرة إلى إمكانية إدارتها من الإعدادات. بقيت شجرة الموقع وأوامر البحث والتحديث والطباعة والاستيراد والإضافة والتعطيل icon-first وقابلة للوصول.
