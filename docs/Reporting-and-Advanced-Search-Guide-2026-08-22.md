# دليل التقارير والبحث المتقدم في AssetX

> **الحالة:** دليل تنفيذ مرتبط بالواجهة الحالية
> **التاريخ:** 22 أغسطس 2026
> **المستودع:** `Abdulhame709/assetx-enterprise-platform`
> **قاعدة البيانات المحلية:** مؤجلة؛ هذا التغيير لا يشغّلها ولا يطبّق migrations عليها.

## 1. مساحة التقارير المضافة

أصبحت صفحة **التقارير** مساحة تصدير تشغيلية متعددة المصادر بدلاً من أن تكون تصديراً لسجل الأصول فقط. تختار الواجهة مصدر البيانات، ثم الصيغة، ثم حد الصفوف، وبعدها يرسل المتصفح طلباً مصادقاً إلى endpoint حقيقي في backend. تبقى الصلاحيات وعزل الجهة مفروضين في backend، ولا تعتمد الواجهة على إخفاء الزر كحاجز أمني.

| المصدر في الواجهة | Endpoint | الصلاحية | محتوى التقرير |
|---|---|---|---|
| سجل الأصول | `GET /exports/assets` | `export.assets` | بيانات الأصول الحالية ضمن الجهة. |
| سجل الحركات | `GET /exports/movements` | `export.movements` | طلبات الحركات وحالاتها وبياناتها التشغيلية. |
| نتائج الجرد | `GET /exports/inventory` | `export.inventory` | دورات الجرد ونتائج السجلات والفروقات. |
| أحداث التدقيق | `GET /exports/audit` | `export.audit` | أحداث الأمان والتغييرات ضمن الجهة. |
| بيانات لوحة المؤشرات | `GET /exports/dashboard` | `export.dashboard` | المؤشرات التشغيلية التي يوفرها مصدر لوحة المؤشرات. |

يظهر مصدر التقرير للمستخدم فقط عندما تملك جلسته صلاحية التصدير المقابلة. وإذا لم يملك أي صلاحية تصدير، تعرض الصفحة رسالة واضحة بدلاً من محاولة استدعاء endpoint غير مسموح.

## 2. الصيغ المتاحة

تدعم endpoints التصدير الحالية الصيغ الثلاث التالية:

| الصيغة | الاستخدام الأنسب | طريقة التنزيل |
|---|---|---|
| CSV | التحليل في Excel أو Power Query أو الاستيراد إلى أدوات أخرى. | ملف نصي مفصول يعاد تنزيله من stream الخادم. |
| XLSX | العمل اليومي في Excel مع الاحتفاظ ببنية ورقة عمل. | ملف Excel يولده backend من المصدر المحدد. |
| PDF | العرض والطباعة والمشاركة كوثيقة ثابتة. | ملف PDF يولده backend من المصدر المحدد. |

تستخدم الواجهة العقد الموحد `downloadReportExport({ resource, format, limit })`. يتضمن الطلب `format` و`limit` في query string، ويرسل رمز الوصول JWT تلقائياً. يستخرج المتصفح اسم الملف من `Content-Disposition` القادم من backend، مع اسم احتياطي إذا لم يرسله الخادم.

## 3. حدود الصفوف وكيفية تخصيصها

يوجد في مساحة التقارير حقل واحد باسم **حد الصفوف**. القيمة الافتراضية في الواجهة هي **10,000 صف**، ويسمح الحقل بقيم صحيحة من **1 إلى 100,000 صف**. القيمة المختارة تطبق على مصدر التقرير والصيغة المختارين في الطلب نفسه.

| الحالة | القيمة الحالية |
|---|---:|
| القيمة الافتراضية في الواجهة | 10,000 صف |
| الحد الأدنى في الواجهة | 1 صف |
| الحد الأعلى في الواجهة | 100,000 صف |
| القيمة الافتراضية في backend عند غياب `limit` | 10,000 صف |
| هل يختلف الحد تلقائياً حسب CSV/XLSX/PDF؟ | لا؛ الحد الحالي موحد للصيغ الثلاث |

لتخصيص العدد كمستخدم، افتح **التقارير**، اختر المصدر، اختر CSV أو XLSX أو PDF، اكتب عدد الصفوف في حقل **حد الصفوف**، ثم اضغط **تنزيل التقرير**. لا تحتاج إلى تغيير الإعداد لكل مصدر؛ الحد يطبق على عملية التنزيل الحالية فقط.

ولتخصيص حدود مختلفة لكل صيغة على مستوى المنتج، يحتاج التنفيذ اللاحق إلى استبدال القيمة المفردة بخريطة إعدادات، مثل `csv: 100000` و`xlsx: 50000` و`pdf: 10000`، ثم تمرير الحد المختار إلى العقد نفسه. لا توجد حالياً قيود format-specific في controller؛ جميع الصيغ تمر عبر `ExportService.generate` مع قيمة `limit` نفسها.

> **ملاحظة تشغيلية:** رفع حد PDF أو XLSX كثيراً قد يزيد زمن الإنشاء وحجم الذاكرة؛ لذلك يبقى الحد الافتراضي المحافظ 10,000 صف مناسباً إلى أن تتوفر مؤشرات أداء فعلية. لا ينبغي إضافة BullMQ أو Redis لمجرد رفع الحد قبل ظهور محفز تشغيلي مثبت.

## 4. توسعة البحث المتقدم

أصبحت صفحة **البحث** تدعم ثلاثة موارد حقيقية، وتستعمل endpoints البحث المتقدم بدلاً من مسار قائمة الأصول العام:

| المورد | Endpoint | الحقول الأساسية |
|---|---|---|
| الأصول | `GET /search/assets` | النص العام، النوع، الموقع، الحالة، الموظف، الباركود، الرقم التسلسلي، الرقم المرجعي، تاريخ الشراء، نطاق السعر، حالة النشاط. |
| الحركات | `GET /search/movements` | الحالة، نوع الحركة، تاريخ الإنشاء من وإلى، والنص العام. |
| التدقيق | `GET /search/audit` | الإجراء، الكيان، معرّف المستخدم، معرّف السجل، تاريخ الإنشاء من وإلى، والنص العام. |

تدعم كل الموارد الفرز والاتجاه والتنقل بين الصفحات. يطبق backend حد البحث الأقصى **100 صف للصفحة**، بينما تبدأ الواجهة بـ20 صفاً ويمكن للمستخدم اختيار قيمة أخرى ضمن هذا الحد. تختلف قائمة الفرز حسب المورد حتى لا ترسل الواجهة أسماء أعمدة غير مسموحة:

| المورد | الحقول القابلة للفرز |
|---|---|
| الأصول | الاسم، كود الأصل، تاريخ الشراء، سعر الشراء، تاريخ الإنشاء، الكمية. |
| الحركات | تاريخ الإنشاء، نوع الحركة، الحالة. |
| التدقيق | تاريخ الإنشاء، نوع الإجراء، اسم الجدول/الكيان. |

## 5. البحث المحفوظ

عندما تملك الجلسة صلاحية `search.save` يظهر قسم **عمليات البحث المحفوظة**. يمكن للمستخدم إعطاء البحث اسماً لا يتجاوز 80 حرفاً، ثم حفظ المورد والفلاتر والنص والفرز والاتجاه وحد الصفحات. العمليات المتاحة هي:

| العملية | Endpoint |
|---|---|
| عرض البحوث المحفوظة | `GET /search/saved` |
| حفظ البحث الحالي | `POST /search/saved` |
| تنفيذ بحث محفوظ | `GET /search/saved/:id/execute` |
| حذف بحث محفوظ | `DELETE /search/saved/:id` |

الملكية ونطاق الجهة يفرضان في backend. عند تحميل بحث محفوظ، تعيد الواجهة تطبيق المورد والفلاتر والفرز وحد الصفوف ثم تبدأ طلباً جديداً؛ لا تنسخ النتائج القديمة محلياً ولا تتجاوز الصلاحيات.

## 6. الحفاظ على تدفق الهاتف

لم تُغيّر هذه المرحلة شاشات تطبيق الهاتف الحالية **الميدان، الدورات، والمزامنة**. بقيت طبقة التخزين المحلي وطابور المزامنة كما هي، وتأكدت الاختبارات المستهدفة من استمرار حفظ اللقطة وإعادة تشغيل الطابور ومعالجة التعارضات. كما أن بحث نتائج الجرد والتقارير يتعاملان مع بيانات backend الحية ولا يحاولان تشغيل قاعدة البيانات المحلية.

## 7. الملفات الرئيسية

| الملف | الدور |
|---|---|
| `web/src/features/search/api.ts` | عقد البحث المتقدم والبحث المحفوظ وتحويل النتائج. |
| `web/src/features/search/use-search.ts` | هوك جلب النتائج مع تثبيت query ومنع الجلب عند غياب الصلاحيات. |
| `web/src/app/(dashboard)/search/page.tsx` | واجهة الموارد والفلاتر والفرز والصفحات والحفظ. |
| `web/src/features/reports/api.ts` | عقد تصدير التقارير متعددة المصادر. |
| `web/src/app/(dashboard)/reports/page.tsx` | مساحة اختيار مصدر التقرير والصيغة وحد الصفوف. |
| `backend/src/api/search/search.controller.ts` | endpoints البحث المتقدم وصلاحياته. |
| `backend/src/api/search/saved-search.controller.ts` | endpoints البحث المحفوظ وصلاحية `search.save`. |
| `backend/src/api/export/export.controller.ts` | endpoints التصدير الخمسة وصلاحياتها. |

## 8. حدود هذه المرحلة

لا تتضمن هذه المرحلة إنشاء بحث عالمي جديد، ولا تعديل مخطط قاعدة البيانات، ولا تطبيق قاعدة محلية، ولا إضافة جدولة بريدية للتقارير. كما لا تعتبر حدود الصفوف بديلاً عن async export؛ إذا ظهرت حاجة إلى ملفات كبيرة أو عمليات طويلة، يجب فتح RFC منفصل يحدد المحفز والصف والـ retry والمراقبة وخطة الرجوع.
