# استئناف المرحلة الوظيفية لوحدة الجرد

تم استئناف العمل مع تجميد تحسينات الأزرار والتنسيق المرئي مؤقتاً. الهدف الحالي هو تقوية الوظائف الأساسية قبل العودة إلى مرحلة التجميل النهائية.

## الحالة قبل الاستئناف

كانت المنصة تدعم إنشاء دورة جرد مع نطاق شامل أو نطاق موقع/نوع أصل، وإنشاء لقطة للأصول النشطة، والبدء والإغلاق، وتسجيل نتيجة أصل واحد، وإعادة العد، والتحقق، والملخصات والفروقات المحسوبة. كما كان backend يوفّر مسار `mobile-snapshot`، لكنه لم يكن ممثلاً في عقد واجهة الويب.

## التغييرات الوظيفية المنفذة

أضيف عقد typed في واجهة الجرد لقراءة لقطة دورة كاملة للاستخدام اللاحق في العميل الميداني والهاتف، مع تحويل بيانات الأصول والمواقع والنتائج إلى نموذج آمن للعرض أو التخزين المؤقت.

تم إصلاح تحديث سجل الجرد ليغيّر الحقول المرسلة فقط، ويسمح بتمرير `null` صراحة لمسح قيمة فعلية أثناء إعادة العد. وفي الوقت نفسه يحافظ التسجيل الأول الذي لا يرسل موقعاً فعلياً على الموقع المتوقع، حتى لا يتحول الأصل الصحيح إلى فرق نقل بالخطأ.

لم تتغير ألوان الواجهة أو ترتيب الأزرار أو تصميم الصفحات في هذه الخطوة.

## التحقق

- Web TypeScript: ناجح.
- Web Vitest: 58 اختباراً ناجحاً.
- Backend TypeScript build: ناجح.
- لا توجد أسرار أو بيانات اعتماد ضمن التغييرات.

## الخطوة الوظيفية التالية

الخطوة التالية هي بناء مسار العميل الميداني: تحميل لقطة الدورة، تخزينها مؤقتاً على الجهاز، تسجيل النتائج عند ضعف الاتصال أو انقطاعه، ثم مزامنة النتائج عند عودة الاتصال مع منع الكتابة فوق نتيجة أحدث والتحقق من الصلاحيات. بعد استقرار هذا المسار، يُربط فرق الموقع بطلب حركة رسمي، ثم تُرحّل تحسينات الأيقونات والتنسيق إلى المرحلة الأخيرة.
