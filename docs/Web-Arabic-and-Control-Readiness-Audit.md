# تدقيق الجاهزية العربية ووظائف التحكم — خط الأساس

## معيار الجاهزية المعتمد

لا تعد الصفحة جاهزة لمجرد ظهورها باتجاه RTL. يجب أن تعرض عناوينها وأوصافها وأزرارها ورسائل نجاحها وأخطائها بالعربية عند اختيار العربية، وأن تملك على الأقل وظيفة تشغيلية واحدة مفيدة أو حالة عدم توفر صريحة تشرح ما ينقص وموعده في الخطة. يطبق هذا المعيار على كل route ظاهر في القائمة الجانبية.

## نتيجة المسح الأولي

أظهر المسح الساكن وجود نصوص إنجليزية ثابتة خاصة في تفاصيل الأصل ولوحة الأصول والامتثال ولوحة المتابعة والتدقيق. كما توجد صفحات موجهة إلى `PlaceholderPage` فقط، وهي: الإدارة، التحليلات، استيراد البيانات، الصيانة، التقارير، البحث، والإعدادات. لا تحقق هذه الصفحات حالياً الحد الأدنى التشغيلي المطلوب، حتى وإن كانت عناوينها قابلة للترجمة.

| مجموعة الصفحات | الحالة الحالية | الإجراء المطلوب قبل اعتبارها جاهزة |
|---|---|---|
| الأصول وتفاصيل الأصل | عمليات أساسية موجودة، مع نصوص إنجليزية ثابتة وأزرار تبويب/إجراءات تحتاج تعريباً واكتمالاً صريحاً | تعريب كل النصوص ورسائل الحالة، وربط أو تعطيل واضح للتبويبات غير المنفذة |
| دورات الجرد وتفاصيلها | تدفق الدورة والعد والتحقق موجود، وقاموس الجرد العربي متاح | اختبار كامل بالعربية ومراجعة رسائل النوافذ والنماذج |
| المواقع والحركات والتدقيق والامتثال | واجهات وبيانات موجودة بدرجات مختلفة | تدقيق نصوص الأزرار والعناوين ورسائل الخطأ لكل شاشة |
| التقارير والتحليلات والصيانة | صفحات مؤقتة | بناء الحد الأدنى التشغيلي ببيانات حقيقية قبل اعتبارها صفحات جاهزة |
| الإدارة والإعدادات والاستيراد والبحث | صفحات مؤقتة | استبدالها بمهام إدارة/إعداد/استيراد/بحث حقيقية أو إظهار حالة عدم توافر دقيقة دون أزرار وهمية |

## قواعد التحكم

1. لا يظهر زر قابل للنقر بلا مسار عمل أو رسالة حالة صريحة.
2. الأفعال الحساسة مثل الإغلاق والنقل والاعتماد تعرض تأكيداً ومحصلة واضحة.
3. الأفعال غير المتاحة بعد تعرض كحالة «قيد الإعداد» مع سبب واضح، بدلاً من توهيم المستخدم بأنها تعمل.
4. لا ينتقل العمل إلى وحدة جديدة قبل تحقق العربية الوظيفية والحد الأدنى التشغيلي في الصفحة التي يجري العمل عليها.

## ترتيب التنفيذ

1. إصلاح صفحة الدخول واستعادة الجلسة حتى يمكن التحقق المرئي من التعريب.
2. تعريب صفحات الأصول وتفاصيلها ومكوناتها، ثم الجرد والمواقع والحركات والتدقيق والامتثال.
3. استبدال الصفحات المؤقتة بحد أدنى عملي: التقارير والتحليلات، ثم البحث، ثم الصيانة، ثم الإدارة/الإعدادات/الاستيراد.
4. إجراء جولة فحص لكل زر وحالة خطأ ونجاح بالعربية قبل الانتقال إلى جرد المواقع الذكي أو وحدة أخرى.
