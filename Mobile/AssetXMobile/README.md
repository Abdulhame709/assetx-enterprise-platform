# AssetX Mobile

هذا هو **مصدر تطبيق الجرد الميداني** لمنصة AssetX Enterprise. التطبيق مبني بـ Expo وReact Native، ويحتوي على شاشات الميدان والدورات والمزامنة وإعداد اتصال Backend، مع SQLite على Android/iOS وتخزين آمن لرموز الجلسة.

## التشغيل المحلي

من داخل هذا المجلد شغّل الأوامر التالية:

```bash
pnpm install
pnpm dev
```

بعدها افتح Expo Go على هاتف Android وامسح رمز QR الظاهر. عند فتح التطبيق، اكتب رابط Backend المباشر. في بيئة Windows المحلية يكون الرابط بالشكل التالي:

```text
http://عنوان-IP-الكمبيوتر:3001
```

لا تستخدم `localhost` على الهاتف، ولا تستخدم منفذ قاعدة البيانات `5432` أو منفذ واجهة Web `3000`.

## ما يتصل به التطبيق

يستخدم التطبيق مسارات AssetX Backend التالية فقط:

| العملية | المسار |
|---|---|
| تسجيل الدخول وتجديد الجلسة | `/auth/login` و`/auth/refresh` |
| عرض دورات الجرد | `/inventory/cycles` |
| تنزيل بيانات دورة ميدانية | `/inventory/cycles/:id/mobile-snapshot` |
| مزامنة النتائج المحلية | `/inventory/cycles/:id/sync` |

رموز الجلسة تحفظ في Secure Store على الهاتف. أمّا الدورات والنتائج غير المرسلة فتحفظ في SQLite على Android وiOS. عند العمل من معاينة Web يستخدم التطبيق تخزيناً محلياً بديلاً لأغراض العرض فقط.

## حدود الإصدار الأول

هذا المصدر لا ينفذ GPS أو الصور أو Push أو إدارة الأجهزة. كما لا ينفذ نقل الأصل تلقائياً عند اختلاف الموقع؛ يحتفظ بالنتيجة أو الملاحظة ليبقى قرار النقل خاضعاً للتأكيد والموافقة داخل منصة AssetX.
