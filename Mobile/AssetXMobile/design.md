# تصميم AssetX Mobile

## هدف التطبيق

تطبيق جوال ميداني عربي RTL يعمل في الوضع الطولي 9:16، ومخصص لتنفيذ دورات الجرد في المواقع الفعلية مع الاحتفاظ بالنتائج على الجهاز عند انقطاع الشبكة، ثم مزامنتها بأمان مع منصة AssetX Enterprise. لا يكرر التطبيق لوحات الإدارة أو التقارير المتقدمة الموجودة في Web؛ بل يركز على أقل عدد من الخطوات التي يحتاجها جامع الجرد.

## قائمة الشاشات

| الشاشة | المحتوى والوظيفة |
|---|---|
| إعداد الاتصال وتسجيل الدخول | إدخال رابط Backend، حفظه محلياً، وتسجيل الدخول باسم المستخدم وكلمة المرور؛ تخزن رموز الجلسة فقط في Secure Store. |
| الميدان | حالة الاتصال، الدورة النشطة، زر تنزيل دورة، ملخص العمليات المعلقة، وزر بدء العمل الميداني. |
| الدورات | قائمة الدورات المحفوظة على الهاتف، حالة التنزيل، وعدد السجلات المتوقعة والمنجزة. |
| تفاصيل الدورة | اختيار موقع العمل، فلتر المواقع الفرعية، تقدم العمل، وقوائم: بانتظار الجرد، تم التأشير، اختلاف موقع، ولم يُجرد. |
| المسح والبحث | كاميرا لمسح QR/Barcode أو إدخال كود الأصل يدوياً؛ تظهر بطاقة الأصل والموقع المتوقع. |
| إدخال نتيجة الجرد | تأكيد "موجود في هذا الموقع" بزر واحد، أو تعديل الكمية، أو تسجيل اختلاف الموقع مع ملاحظة اختيارية. |
| اقتراح النقل | مقارنة الموقع المتوقع بالموقع المرصود، تأكيد اقتراح النقل فقط، دون تغيير موقع الأصل الرئيسي تلقائياً. |
| المزامنة | عرض طابور العمليات المحلي بعدد pending وsynced وconflict وerror، مع زر مزامنة وإعادة المحاولة. |
| إعدادات الجهاز | تغيير رابط Backend، عرض المستخدم المتصل، تسجيل الخروج، ومسح البيانات المحلية بعد تأكيد صريح. |

## التدفقات الرئيسية

1. يفتح المستخدم التطبيق ثم يحفظ رابط Backend المؤسسي ويسجل الدخول.
2. يفتح تبويب **الميدان**، ثم ينزّل لقطة دورة جرد إلى الجهاز.
3. يفتح تبويب **الدورات** ويختار الدورة والموقع العملي، ثم يستخدم المسح أو البحث لتحديد الأصل.
4. يضغط **موجود في هذا الموقع** عند التطابق، أو يسجل اختلاف موقع؛ الاختلاف ينشئ اقتراح نقل خاضعاً للاعتماد ولا ينقل الأصل تلقائياً.
5. تحفظ كل النتيجة في SQLite وطابور مزامنة محلي حتى عند انقطاع الشبكة.
6. يفتح المستخدم تبويب **المزامنة** عند عودة الاتصال، فيرسل العمليات ويراجع التعارضات أو الأخطاء القابلة لإعادة المحاولة.

## اختيارات الألوان والتخطيط

الخلفية الأساسية هي كحلي ميداني عميق `#0B2545`، وتستخدم البطاقات البيضاء `#F8FAFC` لرفع الوضوح تحت الإضاءة القوية. اللون التفاعلي الرئيسي أزرق `#2563EB`، وحالة الاتصال الناجح أخضر `#16A34A`، والتحذير كهرماني `#D97706`، والخطأ أحمر `#DC2626`. النص الداكن `#0F172A` والنص الثانوي `#64748B`.

تستخدم الواجهة أزراراً كبيرة بارتفاع لا يقل عن 52 نقطة، مع شريط تبويب سفلي ثابت: **الميدان، الدورات، المزامنة**. توضع الإجراءات المتكررة في أسفل الشاشة ضمن منطقة يسهل الوصول إليها بالإبهام. يحترم التطبيق Safe Area ويستخدم عناوين قصيرة وتغذية راجعة واضحة لكل عملية.

## حدود المرحلة الأولى

تتضمن المرحلة الأولى الاتصال، المصادقة، تنزيل لقطة الدورة، التخزين المحلي، مسح QR/Barcode، حفظ العد محلياً، ومزامنة العمليات مع Backend. لا تتضمن GPS أو الصور أو Push أو إدارة الأجهزة أو التقارير الإدارية، لأنها تحتاج قراراً خاصاً بالسحابة وسياسة بيانات مستقلة.
